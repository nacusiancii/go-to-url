# Go to URL — Privacy Policy

_Last updated: October 4, 2026_

Go to URL does not collect, store, transmit, sell or share any personal data.

- **Tab titles and addresses** are read only to show the tab list in the prompt. They're held in memory while the prompt is open, and they never leave your browser.
- **Recently closed tabs** are read only so the prompt can reopen a tab you closed with it.
- **What you type** in the prompt is either opened as an address or passed to your browser's default search engine, exactly as if you'd typed it in the address bar.
- The extension makes no network requests of its own, uses no analytics, and loads no remote code.
- Nothing is saved to storage.
