Notes on writing a small tiling window manager

12 min read

Most of the work in a window manager is not tiling. It is everything around tiling: focus rules, floating dialogs that refuse to stay where you put them, and the long tail of applications that each have their own idea of what "fullscreen" means.

Fullscreen is where browsers get interesting. Press F11 and the toolbar disappears, which is the point, until you want to go somewhere else and realise the address bar went with it.

The layout code itself turned out to be about two hundred lines. A binary tree of splits, a ratio per node, and a function that walks the tree handing out rectangles. Everything else is bookkeeping.

The part that took longest was deciding what should happen when a window asks to be fullscreen while another one already is. There is no right answer, only a choice you have to make and then document.
